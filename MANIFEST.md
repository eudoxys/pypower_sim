# MANIFEST

Map of the `eudoxys/pypower_sim` repository. Every tracked file is covered
by one row or glob below; check with `python .github/check_manifest.py`.
Update this file in the same PR that adds, moves, or deletes a file.

## Start here

1. `CLAUDE.md` — conventions, known rough edges, working rules
2. `pypower_sim/__init__.py` — package docs and public API
3. `pypower_sim/ppmodel.py` — the case data model
4. `pypower_sim/ppsolver.py` — powerflow, OPF, OCE, and time-series solvers

## Task index

- Add a solver: `pypower_sim/ppsolver.py` (`solve_*`); test in `pypower_sim/_test/test_ppsolver.py`
- Add a case table or column index: `idx_*` classes in `pypower_sim/ppmodel.py`; `PPModel.standard_idx`
- Change time-series inputs/outputs: `pypower_sim/ppdata.py`, `PPSolver.run_timeseries` in `pypower_sim/ppsolver.py`
- Add a CLI command or option: `pypower_sim/cli.py`, `pypower_sim/__init__.py` Syntax section, `pypower_sim/_test/test_cli.py`
- Add a test case: `pypower_sim/_test/data/`, its `README.md`, and `SMALL_CASES` in `pypower_sim/_test/conftest.py`
- Update docs: docstrings, then `make docs`; `README.md` examples
- Release: `pyproject.toml` version; see the eudoxys-package skill checklist
